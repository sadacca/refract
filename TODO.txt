Pipeline architecture note: GitHub Actions workflows are composite (ingest + eval
in one job). The data layer already provides logical separation via hash-based
dedup and cached article text. Separate workflows exist only where triggers differ:
  - precompute.yml     → triggers on taxonomy.json changes
  - batch_eval.yml     → composite ingest+eval; triggers on article_urls.txt push or manual dispatch
  - build_index.yml    → called at end of batch_eval, or manual dispatch
  - precompute_examples.yml → manual only; human review required before output is used

PHASE 2 — CORE PIPELINE
=========================================
Depends on Phase 1 complete (at least 7 verified Tier 1 entries).

[ ] 2.1  Write src/refract/llm_client.py
          Thin abstraction: model name + API key → structured JSON call.
          Handles Gemini 2.0 Flash (primary). Swappable via config.
          Exponential backoff retry (4 attempts, 2^n seconds).
          Returns parsed JSON or raises with full error context.

[ ] 2.2  Write src/refract/ingest.py
          - trafilatura URL fetch + clean (primary)
          - Guardian API article fetch by URL or search (secondary)
          - sha256(url+text) as article_id
          - Check data/processed/ for existing article_id; return cached if found
          - Write raw article text to data/cache/{hash}_raw.json

[ ] 2.3  Write src/refract/bias_eval.py
          4-pass evaluation pipeline. Loads precomputed blocks from data/precomputed/;
          does NOT assemble prompts at runtime.
          Pass 1: Category triage (1 LLM call) — which of 10 categories are present?
          Pass 2: Bias identification (1 call per flagged category, injects bias_blocks
                  + reference examples as few-shot anchors)
          Pass 3: Recall probes (1 call per unflagged category — forces model to
                  articulate absence, not just skip)
          Pass 4: LLM judge (1 cross-model call per article — pointwise, one criterion,
                  locked rubric with evidence anchoring, few-shot calibration)
          Output: evaluation JSON matching schema in REQUIREMENTS.md / EVALUATION_FRAMEWORK.md
          Write result to data/processed/{article_hash}_{fw_version}.json

[ ] 2.4  Write src/refract/reframe.py
          Three modes: Neutralize / Steelman / Annotated
          Loads reframe_blocks from data/precomputed/.
          Injects evaluation results + article text.
          Constraint in prompt: preserve facts, do not add claims, flag gaps.

[ ] 2.5  Write scripts/batch_eval.py
          Headless pipeline: reads data/input/article_urls.txt, runs ingest + eval
          per article, skips already-processed hashes, respects rate limit delay
          (default 5s between articles to stay within Gemini 30 req/min).
          Accepts CLI args: --url-file, --skip-cached, --max, --model-override.

[ ] 2.6  Write scripts/build_index.py
          Reads all data/processed/*.json, rebuilds:
            - data/processed/index.json (manifest, no article text)
            - data/processed/stats.json (aggregations)
            - data/processed/bias_frequency.json (per-bias hit count/rate)

PHASE 3 — GITHUB ACTIONS WORKFLOWS
=========================================
[ ] 3.1  .github/workflows/precompute.yml
          Trigger: push to bias_index/taxonomy.json or src/refract/prompts/
          Runs scripts/precompute.py, commits data/precomputed/ back to main.
          Fails fast if framework_version not incremented.

[ ] 3.2  .github/workflows/batch_eval.yml  ← COMPOSITE: ingest + eval in one job
          Trigger: workflow_dispatch (with inputs) OR push to data/input/article_urls.txt
          Inputs: url_file, model_override, skip_cached (bool), max_articles (int)
          Steps: checkout → setup-python → pip install (cached) →
                 verify data/precomputed/ is current for framework_version →
                 python scripts/batch_eval.py →
                 python scripts/build_index.py →
                 git add data/processed/ → git commit → git push main
          Concurrency: group: batch-eval, cancel-in-progress: false

[ ] 3.3  .github/workflows/build_index.yml
          Trigger: workflow_dispatch only (for manual reconciliation)
          Runs scripts/build_index.py, commits updated index/stats files.

[ ] 3.4  .github/workflows/precompute_examples.yml
          Trigger: workflow_dispatch only
          Runs scripts/precompute_examples.py --status pending
          Commits data/pending_examples/ (not taxonomy.json — human review required first)

DECISION LOG
==========================
2026-05-31  Pipeline architecture: composite ingest+eval in batch_eval.yml (not
            separate workflows). Data layer provides logical separation via hash-based
            dedup and data/cache/. Re-fetching is fast and free; separate workflows
            add complexity with no benefit at this scale.

2026-05-31  Tier 1 taxonomy: 7 biases fully enriched before any evaluation runs.
            Build sequence: enrich → precompute_examples → human review → precompute.py
            → pipeline runs.

2026-05-31  Free API stack: Gemini 2.0 Flash (primary, 1500 req/day), Guardian API
            (article source, 500 req/day), trafilatura (URL scraping, local/free).
            LLM client abstracted; model is a config swap.
