NEXT STEPS TO REACH END-TO-END WORKING
=========================================
These must happen in order before the pipeline runs on a real article:

1. ADD GEMINI_API_KEY to environment (.env file locally, GitHub Actions secret for CI)
2. RUN precompute_examples.py to generate candidate reference examples:
     python scripts/precompute_examples.py
3. REVIEW candidates in data/pending_examples/ — accept into taxonomy.json:
     For each bias_id.json in data/pending_examples/:
       - Copy positive/near_miss/contrast into taxonomy.json reference_examples
       - Set examples_status: "verified"
       - Commit
4. RUN precompute.py to rebuild blocks with verified examples:
     python scripts/precompute.py
5. RUN pipeline on one article end-to-end:
     python -c "
     from src.refract.ingest import fetch_url
     from src.refract.bias_eval import evaluate_article
     article = fetch_url('https://www.theguardian.com/...')
     result = evaluate_article(article)
     print(result['summary'])
     "
6. LAUNCH Streamlit and verify UI:
     streamlit run app.py
