# Taxonomy Changelog

## v0.2.0 — 2026-06-23
- Replaced taxonomy with 14 entries sourced from "Cognitive Biases in Written Text:
  Operationalized Definitions, Diagnostic Criteria, and Examples"
- Added entries: Hindsight Bias, Conjunction Fallacy, Base Rate Neglect, Sunk Cost
  Fallacy, Overconfidence Bias, Scope Insensitivity, Gambler's Fallacy, Hyperbolic
  Discounting, Actor-Observer Asymmetry, Dunning-Kruger Effect (Overestimation Variant)
- Removed entries not present in the source document: Confirmation Bias,
  Negativity Bias, In-Group Bias
- Replaced definitions and examples for retained entries: Availability Heuristic,
  Anchoring (renamed Anchoring Effect), Framing Effect, Fundamental Attribution Error
- Added a `contrast_statement` field to every entry, capturing the document's
  "distinguishing biased from unbiased text" diagnostic criteria
- Archived v0.1.0 taxonomy to bias_index/archive/taxonomy_v0.1.0.json
- All entries status: provisional (reference_examples pending human verification)
